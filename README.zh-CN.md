# Pathport

把文件夹发给别人之前，先检查它在另一套系统上会不会撞名。

[在线使用](https://yougan001.github.io/pathport/) · [English](README.md)

例如，`Docs/a.txt` 和 `docs/b.txt` 在部分系统上属于两个文件夹，到了另一台电脑却可能合并。只检查最后一段文件名，发现不了这个问题。

Pathport 会分析完整目录树，给出原路径与副本路径的对照。目录一旦需要改名，下面的文件会一起跟着调整，不会分别乱改。

## 怎么用

1. 选择文件夹，或者粘贴路径列表。路径使用 `/` 分隔，每行一条。
2. 设置解压目标文件夹需要预留的路径长度，默认 40。
3. 查看大小写冲突、Unicode 重名、Windows 保留名称、非法字符和过长路径。
4. 下载 JSON 对照清单；如果选择了实际文件，还能导出一份 ZIP 副本。

检查名称不需要读取文件内容。只有点击导出 ZIP，才会在浏览器里读取选中的文件。原文件不改名、不覆盖，也不会上传到服务器。

## 需要先知道的限制

- 最多检查 10,000 个文件、32 层路径；ZIP 内容上限 100 MiB。
- ZIP 中的 `files/` 是副本，外面的清单保存原名与新名。清单可能包含敏感文件名，分享前请检查。
- 文件内容保持不变，但权限、时间戳、空文件夹和符号链接不保留。
- 改名可能让相对链接、代码 import 或工程引用失效。工具不会修改文件内容来修复这些引用。
- Unicode 与大小写检查是保守规则，不是每个文件系统的精确模拟。120 字节的单段名称预算、240 个 UTF-16 单元的完整路径预算，是工具自己的交付限制。
- 路径仍然过长时，不会偷偷展平目录，也不会继续导出。需要缩短源目录名称或选择更短的解压目标路径。
- 粘贴路径只能生成报告，不能凭路径拿到本地文件。文件夹选择需要浏览器支持。

测试和本地运行方法见 [英文说明](README.md)。欢迎带一个脱敏后的最小路径列表来提 issue。
